# Velora Vision

Программа для компьютера в клубе: по просьбе клиента вырезает момент его
удара из записи камеры и отправляет видео клиенту через клубный бот.

**Для пользователя:** скачать `VeloraVision-windows.zip` из релиза
`vision-latest`, распаковать, открыть `VeloraVision.exe`. Инструкция лежит в
архиве (`README.txt`). Вводится только токен бота владельца и данные камеры,
для каждой камеры выбирается её стол.

## Как устроено

- Одна обычная программа с окном (tkinter), без Python и терминала у
  пользователя. Нарезку делает ffmpeg из пакета, никакого распознавания
  картинки нет (раньше программа считала людей у столов и ловила удары;
  это убрано как лишнее).
- Клуб определяется по токену бота владельца: функция
  `supabase/functions/vision-sessions` по токену отдаёт столы клуба, функция
  `vision-clips` выдаёт заявки клиентов и принимает готовый ролик.
- Настройки: `%APPDATA%\VeloraVision\settings.json` (токен и адреса камер
  зашифрованы DPAPI).

## «🎬 Мой удар» (ролик по просьбе клиента)

Клиент в клубном боте нажимает «🎬 Мой удар», выбирает стол и пишет время
(день выбирается в календаре, время пишется как `21:47`). Программа вырезает 30 секунд вокруг этого момента
из **записи самой камеры** (карта памяти или регистратор, как в SmartPSS Lite)
и сервер присылает ролик клиенту. Своя запись не ведётся, место на диске не
нужно.

- Работает с камерами Dahua / Imou / Amcrest: адрес записи
  `rtsp://…/cam/playback?channel=N&subtype=0&starttime=…&endtime=…` получается
  из адреса живого потока (`/cam/realmonitor`), время в часовом поясе клуба
  (`clips/archive.py`).
- Раз в 8 секунд программа спрашивает функцию `vision-clips`, нет ли заявок на
  её столы, и заодно сообщает, какие столы умеет резать: поэтому кнопка в боте
  появляется сама и пропадает, если компьютер выключен (`clips/client_clips.py`).
- Стол каждой камеры выбирается в её настройках (имя должно совпадать с
  названием в программе Velora Club). Камеры другой марки пропускаются.
- Кнопка «Проверить запись камеры» берёт несколько секунд из архива
  десятиминутной давности: так видно, что камера отдаёт запись.
- Заявку принимает база (`bot_clip_request`): время не старше 60 дней (сколько записи хранит сама камера, зависит от карты памяти), не
  «только что», в это время за столом шла игра, не больше одной заявки в
  работе и 5 в час на клиента. Заявка, которую никто не взял за 10 минут,
  закрывается, клиенту приходит «не получилось».

## Разработка

    pip install -r requirements-dev.txt
    python -m pytest
    python app.py                    # окно из исходников
    python app.py --selftest         # проверка, что всё нужное на месте
    python scripts/build.py          # собрать dist/VeloraVision (PyInstaller)

Сборку под Windows делает `.github/workflows/vision-build.yml`: тесты,
упаковка, самопроверка упакованной программы, архив и релиз `vision-latest`.

Сторонние компоненты и лицензии: `THIRD_PARTY_NOTICES.md`.
