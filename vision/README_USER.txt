VELORA VISION: камеры в клубе
=============================

1. Распакуйте папку целиком (например, на рабочий стол). Не запускайте
   программу из архива.
2. Откройте VeloraVision.exe. Если Windows спросит, нажмите «Подробнее» →
   «Выполнить в любом случае».
3. Вкладка «1. Бот»: вставьте токен бота владельца (из @BotFather): кнопка
   «Вставить» или правая кнопка мыши → «Вставить» (Ctrl+V тоже работает при
   любой раскладке). Нажмите «Проверить подключение». Впишите канал для роликов с ударами и нажмите
   «Проверить канал».
4. Вкладка «2. Камеры»: «Добавить камеру…», впишите IP-адрес, логин и пароль
   камеры (программа сама подберёт адрес потока; кнопка «Найти камеры в
   сети» поможет узнать IP).
5. Выберите камеру, нажмите «Зоны столов…»:
   - «Где стоят играющие»: обведите мышью пол вокруг стола;
   - «Сукно стола»: обведите игровое поле (для записи ударов).
   Рисуйте обе зоны для каждого стола: они нужны для разного (люди и
   сеансы; запись ударов). Кнопка «Как видит программа…» покажет, правильно
   ли найдены люди. Если картинка лежит на боку, в «Изменить камеру» есть
   поворот; если сжата в квадрат, выберите «Основной поток».
6. Вкладка «Главная»: «Запустить слежение». Окно можно свернуть.

Чтобы программа запускалась вместе с Windows: вкладка «Настройки».

Где хранятся настройки: %APPDATA%\VeloraVision (Файл → Открыть папку с
данными). Токен и пароли камер там зашифрованы.
Ролики не хранятся: после отправки в канал файл сразу удаляется.
В канал уходят только удары, после которых шар забит в лузу (вкладка
«Настройки» → «Запись красивых ударов»). Счётчик на «Главной» показывает,
сколько ударов найдено и сколько шаров ушло в лузу.
