# Velora Club

Windows-приложение управления клубом на Flutter, подключённое к Supabase-проекту `club-control`.

## Готовая сборка

Запускаемый файл находится в:

`build/windows/x64/runner/Release/velora_club.exe`

При переносе на другой компьютер копируйте всю папку `Release`, а не только EXE.

## Возможности

- карта столов и игровые сессии;
- кассовые продажи и оплата;
- бронирования и очередь;
- клиенты и программа лояльности;
- чеки и предпросмотр печати;
- кассовые смены;
- товары и склад;
- расходы и отчёты;
- управление реле;
- сотрудники и настройки клуба.

## Разработка

```powershell
flutter pub get
flutter run -d windows
```

Проверка и release-сборка:

```powershell
flutter analyze
flutter test
flutter build windows --release
```

В приложении используется только публичный клиентский ключ Supabase. Доступ к данным контролируется существующими Auth и RLS-политиками проекта.
